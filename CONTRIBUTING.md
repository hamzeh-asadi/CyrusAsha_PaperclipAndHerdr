# Contributing Guidelines
Keep team operations idempotent and add an offline test for behavior changes. For UI copy, update both `fa` and `en` entries in `dashboard/strings.json` with matching placeholders. Check both directions before refreshing the sample gallery. See [development and screenshot instructions](dashboard/CONSTRUCTION.md); do not contribute private company data or terminal output.
