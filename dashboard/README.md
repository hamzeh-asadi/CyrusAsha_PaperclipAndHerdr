# Unified Dashboard for Paperclip+Herdr

یک داشبورد یکپارچه که همزمان تمام ایجنت‌ها، تیکت‌ها و خروجی‌ها را از یک مرکز فرمان (Paperclip) کنترل می‌کند.

## ویژگی‌ها

- **اسکن خودکار ایجنت‌ها**: لیست کامل ایجنت‌ها از Paperclip API
- **بیدار کردن با heartbeat**: هر ایجنت را با یک کلیک بیدار کنید
- **نمایش خروجی**: خروجی اخیر هر ایجنت را از Herdr بگیرید
- **مدیریت تیکت‌ها**: لیست تیکت‌ها به تفکیک وضعیت و ایجنت
- **پرامپت دستی**: ارسال دستی دستور به هر ایجنت
- **Polling خودکار**: هر ۵ ثانیه وضعیت سیستم را بروزرسانی می‌کند

## ساختار

- `app.py`: بک‌اند Python که API های Paperclip و Herdr را مدیریت می‌کند
- `index.html`: داشبورد UI که با API ها کار می‌کند

## پیش‌نیازها

- Python 3.10 یا بالاتر
- Paperclip در حال اجرا روی `http://localhost:3100`
- Herdr نصب شده و در PATH
- هر سه با یک کاربر ویندوز اجرا شوند

> داشبورد هیچ وابستگی بیرونی (`pip install`) لازم ندارد و فقط از کتابخانهٔ استاندارد پایتون استفاده می‌کند: `http.server` برای سرور، `urllib.request` برای تماس با API پیکرکلیپ و `subprocess` برای اجرای Herdr CLI. نیازی به نصب Flask یا urllib3 نیست.

## نصب و اجرا

1. بررسی دسترسی به API:
   ```bash
   # در یک ترمینال جداگانه
   npx paperclipai run
   ```

2. اجرای داشبورد:
   ```bash
   cd dashboard
   python app.py
   ```

3. باز کردن داشبورد:
   ```
   http://localhost:8000
   ```

## محیط‌های مختلف

می‌توانید از متغیرهای محیطی برای تنظیم دیتابیس استفاده کنید:

```bash
export PAPERCLIP_API_URL=http://localhost:3100
export PAPERCLIP_COMPANY_ID=YOUR_COMPANY_ID
export HERDR_HOST=localhost
export HERDR_PORT=50800
export AGENT_PING_TIMEOUT=2000
export DASHBOARD_HOST=0.0.0.0
export DASHBOARD_PORT=8000
python app.py
```

### خواندن `dashboard/.env`

`app.py` در زمان import تابع `load_env_file()` را صدا می‌زند و فایل `dashboard/.env` را می‌خواند:

- متغیرهای محیطی واقعی **همیشه مقدم‌اند**؛ فایل فقط کلیدهایی را پر می‌کند که قبلاً تنظیم نشده‌اند.
- فایل با `utf-8-sig` خوانده می‌شود، پس BOM نوشته‌شده توسط `Set-Content -Encoding UTF8` در PowerShell مشکلی ایجاد نمی‌کند.
- خط‌های خالی و خطوطی که با `#` شروع می‌شوند نادیده گرفته می‌شوند و کوتیشن دور مقدار حذف می‌شود.
- اگر `.env` وجود نداشته باشد، همان مقادیر پیش‌فرض داخل کد استفاده می‌شوند.

## محدودیت‌ها

- برای دریافت خروجی واقعی ایجنت، Herdr باید نصب و در PATH باشد
- اگر هر سه با کاربرهای متفاوت اجرا شوند، وصل نمی‌شوند
- خروجی دستی (پرامپت) هنوز تکمیل نشده است
